# Clippy Comics

A convenient site for viewing and discussing the in-development Clippy Comics saga.

Currently displays the first half of the year, ahead of schedule for testing purposes. The user can navigate between comics, as well as anonymously comment on each comment.

Future innovations could include a Forum page, a Fan Art page, a "Subscribe to Email" page, and a "Contact the author" page (all accessible through a top-level banner). UI could also be added to make the website more appealing, as it is presently very basic.
